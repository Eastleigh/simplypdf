# SimplyPDF — AI Income Intelligence Platform

AI-powered platform that helps beginners discover profitable digital business opportunities and launch them rapidly using AI automation.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS 4, Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project Structure

```
src/
├── app/
│   ├── layout.tsx          # Root layout with fonts & metadata
│   ├── page.tsx            # Landing page
│   └── globals.css         # Theme & global styles
└── components/
    └── landing/
        ├── Navbar.tsx       # Fixed navigation
        ├── Hero.tsx         # Hero section with CTA
        ├── Features.tsx     # Feature grid
        ├── TrendDashboard.tsx # Live trend intelligence preview
        ├── AIBuilder.tsx    # AI business builder demo
        ├── Pricing.tsx      # Pricing tiers
        ├── SocialProof.tsx  # Testimonials & live activity
        ├── FinalCTA.tsx     # Final call-to-action
        └── Footer.tsx       # Site footer
```
